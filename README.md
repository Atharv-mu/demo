# Demo

A simple beginner-friendly HTML project created as a first repository to learn GitHub, web development, and version control.

## Overview

This project contains a minimal static webpage that displays a basic "Hello World" message. It is intentionally simple and serves as a starting point for learning how to:
- create and manage a GitHub repository
- write HTML
- open a webpage locally
- collaborate with others using pull requests

## Project Structure

```bash
demo/
├── README.md
├── index.html
```

## Files

- `index.html` — the main HTML file for the webpage
- `README.md` — project documentation and setup instructions

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AyushMalviya9479/demo.git
cd demo
```

### 2. Open the project

You can open `index.html` directly in your browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Example Output

The page currently renders:
